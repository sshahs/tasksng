## Self-hosted web version

TasksNG now also runs in a browser. The new `tasksng-server` serves the same interface and does the
syncing with Baikal itself: you sign in with your Baikal username and password, and every account
gets its own cache, settings and reminders on the server. Tabs update live, so a task you add on
one computer shows up in another browser right away.

It ships as a Docker image for amd64 and arm64:

```sh
docker run -d -p 8080:8080 \
  -e TASKSNG_CALDAV_URL=https://dav.example.com \
  -v tasksng-data:/data \
  ghcr.io/sshahs/tasksng:0.4.0
```

`TASKSNG_CALDAV_URL` ties the server to your Baikal, and the sign-in screen then asks only for a
username and password. Reminders show in the open tab, and as browser notifications when the tab
is in the background. Put the server behind HTTPS before using it over a network. The README's
[Self-hosting with Docker](https://github.com/sshahs/tasksng#self-hosting-with-docker) section
covers the settings, a reverse proxy, private certificate authorities and updates.

## Faster installs on NixOS

Nix builds now come from the `tasksng.cachix.org` binary cache, for x86_64 and aarch64, so
installing or updating downloads the finished package instead of compiling it for 10 to 20
minutes. Add the cache once:

```nix
nix.settings = {
  extra-substituters = [ "https://tasksng.cachix.org" ];
  extra-trusted-public-keys = [ "tasksng.cachix.org-1:FMPrtDc5KohOuU/tBd1bKryTqsz2igCxhkdO/gNn8Zg=" ];
};
```

Don't set `inputs.tasksng.inputs.nixpkgs.follows`, or Nix builds its own copy and compiles again.
`nix profile install github:sshahs/tasksng` works too, and the README now explains it.
