## Reminder icon on Android

Reminders on Android now show the TasksNG check mark in the status bar. In 0.5.1 they showed
Android's generic "i" icon. Download `TasksNG_0.5.2_android.apk` below and install it over the
version you have.

Nothing else has changed. Windows installs update themselves as usual, and the Docker image and
the Nix package are at 0.5.2 too.
