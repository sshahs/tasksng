## Android app

TasksNG now runs on Android 8 and later. Download `TasksNG_0.5.0_android.apk` below and open it on
your phone; the first time, Android asks you to allow installing apps from your browser or file
manager. Later versions install over it and keep your tasks and sign-in.

It is the same app with a layout for phones. The lists slide in from the left, tapping a task opens
its details, and long-pressing a task opens its menu. The Back gesture closes whatever is open.

Reminders go to Android's alarm service, so they appear on time with *Snooze 10 min* and *Done*
buttons even when TasksNG isn't running. A reminder added on another device is scheduled the next
time you open TasksNG on the phone.

TasksNG on Android trusts the certificate authorities that come with Android, not ones you
installed yourself. For a Baikal with a self-signed certificate, turn on *Accept invalid TLS
certificates* under *Advanced* when signing in.

## Web version on phones

The self-hosted web version uses the same phone layout in a narrow browser window.
