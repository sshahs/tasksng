## Android: servers on your home network

On Android 17, TasksNG couldn't reach a Baikal server on your home network, such as one running on
a PC or NAS, and signing in ended with "the connection timed out". Android 17 asks apps to get
permission before they connect to devices on the local network, and TasksNG didn't ask.

TasksNG now asks for it when it starts. Android calls it "Nearby devices". Allow it and sign in
again. If you said no, you can turn it on later under Android Settings → Apps → TasksNG →
Permissions → Nearby devices. The timeout message says so too.

Download `TasksNG_0.5.3_android.apk` below and install it over the version you have.

Nothing else has changed. Windows installs update themselves as usual, and the Docker image and
the Nix package are at 0.5.3 too.
