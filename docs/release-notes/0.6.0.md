## Animations

TasksNG now moves. Tasks fade in where they're added while the ones below make room, and deleted
tasks fade out while the rest close the gap. When a task changes place, after a new priority, a
drag and drop or a repeating task moving to its next date, it glides there.

Ticking a task off pops the circle and draws the tick and a line through the title. With completed
tasks hidden, the task stays a moment so you see it done before it slides away.

The sidebar slides in and out (Ctrl+B) and its highlight follows you between lists. Task details
slide in from the right, and on phones they open like a new page. The phone's list drawer can be
swiped shut. Switching between light and dark cross-fades.

It stays smooth with hundreds of tasks. If you turned on "reduce motion" in Windows or Android
settings, TasksNG keeps still.

Download `TasksNG_0.6.0_android.apk` below and install it over the version you have. Windows
installs update themselves as usual, and the Docker image and the Nix package are at 0.6.0 too.
